2.1本课题的任务
本课题的主要任务是构建一个完整的高血压智能问答系统闭环，具体任务分解如下：
数据获取与处理：收集整理高血压相关的权威数据源，包括《中国高血压防治指南（2024 年修订版）》、国家基本药物目录（高血压用药部分）、权威医学百科（如默克诊疗手册）、三甲医院科普文章等。对数据进行清洗、去噪和预处理。
高血压领域本体设计：设计符合医学逻辑的本体结构（Schema），确定实体类型（如：降压药、钙通道阻滞剂、ACEI、高血压分级、低盐饮食）和关系类型（如：属于、治疗、禁忌、导致、副作用是）。
知识抽取与图谱构建：利用自然语言处理技术（NLP），从非结构化文本中抽取实体和关系，构建三元组（Head, Relation, Tail），并存入图数据库。
问答系统后端开发：基于 LangGraph 框架设计问答流程，实现意图识别、实体链接、Cypher 语句自动生成、检索增强生成（RAG）等核心功能模块。
系统集成与测试：开发前端交互界面，集成后端服务，并邀请医学专业人士或利用测试集对系统的回答准确性进行评估和优化。
2.2 重点内容
细粒度的知识抽取：高血压领域的知识非常精细，例如药物的适用人群、用法用量、相互作用等。如何从复杂的医学文本中准确抽取这些属性关系是本课题的重点。我们将重点研究基于  LLM 的少样本（Few-shot）信息抽取技术。
基于图谱的多跳推理：用户的问题往往隐含推理逻辑，例如 “我有痛风，能吃氯沙坦吗？” 系统需要先查询 “氯沙坦” 的属性（是否有排尿酸作用），再查询 “痛风” 的禁忌，结合两者得出结论。实现这种基于路径的推理是系统的核心难点。
混合检索策略（Hybrid Retrieval）：单纯的向量检索（Vector Search）可能丢失精确的实体信息，而单纯的图谱检索（Graph Search）可能无法覆盖长尾问题。本课题将重点研究如何结合关键词检索、向量检索和图谱结构检索，以提高检索的召回率和准确率。
大模型幻觉抑制：在生成答案时，如何强制模型依据检索到的图谱知识回答，而不是依靠其预训练记忆中的潜在错误信息。我们将通过精心设计的 Prompt Engineering 和引用标注（Citation）机制来解决这一问题。
2.3 实现途径
本课题将采用 “Python + Neo4j + LLM + LangGraph + milvus” 的技术栈进行实现，具体技术路线如下：
2.3.1 数据层
数据采集：使用 Python 的 requests、BeautifulSoup 和 Selenium 库编写爬虫，定向爬取 “药智网”、“丁香园” 等网站的高血压药物和疾病详情数据。对于 PDF 格式的指南文档，使用 PyPDF2 或 pdfplumber 以及ocr模型 进行文本解析。
数据存储：
结构化数据：使用 Neo4j 图数据库存储实体和关系。Neo4j 具有高效的图遍历能力，非常适合存储复杂的医学知识网络。
非结构化数据：对于无法完全结构化的长文本（如疾病综述、发病机制），使用 FAISS 或 Milvus 向量数据库存储其文本 Embedding（使用 BGE-M3 或 m3e-base 模型进行向量化）。
2.3.2 算法层
知识抽取：
利用 LLM（如 Deepseek, Qwen）通过 Prompt 进行少样本抽取。
问答流程编排（LangGraph）：
参考现有项目架构，使用 LangGraph 构建有向无环图（DAG）状态机。
节点设计：
Intent_Recognition_Node：使用 LLM 判断用户意图（是查询知识、寻求诊断还是闲聊）。
Entity_Extraction_Node：从用户 Query 中提取关键实体（如 “高血压”、“头晕”）。
Query_Generation_Node：利用 LLM 将自然语言转换为 Neo4j 查询语言（Cypher）。
Graph_Retrieval_Node：执行 Cypher 查询，获取子图数据。
Vector_Retrieval_Node：对 Query 进行向量化，在 FAISS / Milvus中检索相似文档片段。
Answer_Generation_Node：将检索到的图谱知识和文档片段作为 Context，输入 LLM 生成最终回答。
2.3.3 应用层
后端服务：使用 FastAPI 框架构建 RESTful API，提供高并发的问答服务接口。支持流式输出（Streaming Response），提升用户体验。
前端界面：使用 Streamlit 快速搭建 Web 界面，支持文本输入、语音输入（可选）、历史对话展示。界面设计将简洁直观，适合中老年高血压患者使用。
② 软件及工具
开发语言：Python 3.11。
数据库：Neo4j Community Edition（图数据库）、Redis（缓存）、FAISS\Milvus（向量索引）。
深度学习框架：PyTorch, Hugging Face Transformers。
大模型框架：LangChain, LangGraph。
开发工具：PyCharm / VS Code, Git。
